- Description:
This is a simple mathmatics appication, the app.py is to see the numbers 2 and 3 be added and subtracted.
The test_app.py is to test other numbers (including 2 and 3) of adding and subtraction.

- Run app.py:
in the terminal run:

python app.y

- run test cases:
in the terminal run:

python -m unittest discover

if you want to see each individual test show it works run:

python -m unittest discover -v

Jenkins pulls this repo, runs the tests, and reports a pass or fail result.
